# lms-assignment-notifier

Moodle系のLMSから未提出の課題を取得し、Discordに通知するツールです。毎朝の定時通知と、提出済み・未提出の一覧表示ができます。動作確認はIPUT(東京)のLMSで行いました。他の大学のMoodleでは、モバイル用APIが許可されている場合に使えます。

## 2つの版

| | Python版 (`python/`) | GAS版 (`gas/`) |
|---|---|---|
| 毎朝の定時通知 | できる(cron) | できる(トリガー。時刻は最大1時間ずれる) |
| 提出済み・未提出の一覧 | できる | できる(手動実行かウェブアプリ) |
| Discordで `!worklist` | できる(bot) | できない |
| 必要なもの | 常時稼働のPCかサーバー | Googleアカウントだけ |
| 設定の置き場所 | `.env` | スクリプト プロパティ |

定時通知だけでよければGAS版が手軽です。Discordのコマンドで一覧を見たい場合は、Python版を使ってください。

## 始め方

1. [トークンを取得する](docs/get-token.md)
2. Discordで、通知先チャンネルのWebhookを作ってURLをコピーする(チャンネルの編集 → 連携サービス → ウェブフック)
3. 使う版の手順に進む
   - [Python版](python/README.md)
   - [GAS版](gas/README.md)

## 使う前に

- 大学の情報システム利用規程で、自動アクセスや認証情報の取り扱いを確認してください。
- 大学がモバイル用APIを許可していない場合、このツールは使えません。トークン取得の段階で分かります。
- 使い方は、自分のアカウントで、読み取りだけを、1日1回程度にとどめてください。短い間隔の繰り返しや、他人のトークンを預かる使い方はしないでください。

## セキュリティ

- トークンとWebhook URLは秘密の鍵です。コード、Issue、スクリーンショットに含めないでください。
- `.env` はGitに入れません(`.gitignore` で除外済みです)。
- 通知には科目名と課題名が含まれます。他人が参加するチャンネルには送らないでください。
- Discord botは、`DISCORD_ALLOWED_USER_IDS` に書いたユーザーにしか応答しません。
