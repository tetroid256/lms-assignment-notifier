# GAS版

Googleアカウントだけで動きます。サーバーは要りません。毎朝の定時通知と、一覧のDiscord送信ができます。Discordの `!worklist` コマンドは使えません。

## 準備

1. [トークンを取得](../docs/get-token.md)します。
2. 通知先チャンネルで、Discordの Webhook URL を作ります。
3. https://script.google.com で新しいプロジェクトを作ります。
4. エディタの `コード.gs` の中身を、このフォルダの `Code.gs` で置き換えます。
5. 左の歯車「プロジェクトの設定」を開き、「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェックを入れます。エディタに現れた `appsscript.json` を、このフォルダのもので置き換えます。
6. 同じ画面の「スクリプト プロパティ」に、次を追加します。

| プロパティ | 値 |
|---|---|
| LMS_BASE | LMSのURL(例: https://lms.example.ac.jp) |
| LMS_TOKEN | 手順1のトークン |
| DISCORD_WEBHOOK_URL | 手順2のURL |

任意の設定は、次のとおりです。

| プロパティ | 内容 | 既定 |
|---|---|---|
| NOTIFY_HOUR | 定時通知の時刻(0〜23) | 7 |
| DAYS_AHEAD | 定時通知で何日先まで出すか | 7 |
| WORKLIST_PAST_DAYS | 一覧で提出済みを何日前まで遡るか | 14 |
| WORKLIST_FUTURE_DAYS | 一覧で何日先まで出すか | 30 |
| EXCLUDE_KEYWORDS | 名前に含まれていたら除外する語(カンマ区切り) | なし |

## 動作確認と登録

エディタ上部の関数選択で関数を選び、「実行」を押します。初回は権限の承認を求められます。

1. `checkToken` を実行します。実行ログに `OK: ...` と出れば成功です。
2. `sendWorklistNow` を実行します。未提出と提出済みの一覧がDiscordに届きます。
3. `installDailyTrigger` を実行します。毎朝 `NOTIFY_HOUR` の時間帯に、未提出の一覧が届きます。時刻は最大1時間ほどずれます。

登録されたトリガーは、左の時計のアイコン「トリガー」で確認できます。通知を止めるときは `removeTriggers` を実行します。

## ウェブアプリで見る(任意)

「デプロイ → 新しいデプロイ → ウェブアプリ」で、アクセスできるユーザーを「自分のみ」にして公開すると、そのURLを開いたときに一覧が表示されます。他人がアクセスできる設定にはしないでください。

## 注意

- トークンとWebhook URLは、コードに書かず、必ずスクリプト プロパティに入れてください。
- プロジェクトを他の人と共有しないでください。トークンが見えてしまいます。他の人に渡すときは、ファイルを配布してください。
